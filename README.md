# AXI2AXI DMA Controller

This repository contains the AXI-to-AXI DMA Controller project.

Current status: project skeleton and specification setup.

## Planned structure

- doc/ : specifications, architecture, and verification documents
- rtl/ : synthesizable RTL
- model/ : reusable behavioral models
- sim/ : testbench, patterns, scripts, logs, waveforms, and coverage
- lint/ : lint setup
- syn/ : synthesis setup
- .github/workflows/ : CI workflows

The implementation will follow the specification under doc/specification/.
